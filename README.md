# Cassava Yield Analysis in R

A beginner-friendly R programming and statistics project based on the **Cassava Yield Data** assignment.

## Project goals

This repository answers all questions in the assignment:

1. Explore the distribution of variables, missing values, and outliers; transform the data.
2. Investigate:
   - two continuous variables,
   - one continuous + one categorical variable,
   - two categorical variables,
   using graphs and statistical tests.
3. Investigate whether:
   - fertilizer application affects `TotalWeightperhectare` and `TotalTuberperHectare`;
   - tillage method affects `TotalWeightperhectare` and `TotalTuberperHectare`.

## Main statistical methods

- Histograms and boxplots for distributions/outliers.
- Missing-value checks.
- IQR-based winsorization (capping extreme values at the IQR fences).
- Pearson correlation for two continuous variables.
- Welch two-sample t-test for continuous + two-level categorical comparisons.
- Chi-square test of independence for two categorical variables.
- One-way ANOVA for fertilizer comparisons.
- Tukey HSD for post-hoc fertilizer comparisons when appropriate.

## Key results from the supplied dataset

The supplied workbook contains **115 observations and 20 variables**.

- No missing values were found.
- IQR screening identified outliers in several variables, including `No_bigtubers`, `Weigh_bigtubers`, `No_mediumtubers`, `Weight_mediumtubers`, and `TotalWeightperhectare`.
- `TotalWeightperhectare` and `TotalTuberperHectare` had a positive Pearson correlation (r ≈ 0.576, p < 0.001) before winsorization.
- Fertilizer: one-way ANOVA did not show a statistically significant overall fertilizer effect at α = 0.05 for either projected total weight per hectare or projected total tuber number per hectare.
- Tillage: Welch t-tests did not show a statistically significant difference between conventional and minimum tillage for either projected outcome at α = 0.05.
- Tillage and fertilizer are perfectly balanced in this dataset (each tillage group has the same number of observations for each fertilizer code), so the chi-square test of independence has p = 1.

**Important:** These results describe this dataset; they are not a claim about all cassava farmers or all farming conditions.
